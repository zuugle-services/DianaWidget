Diana GreenConnect widget:

ready to embed.

Diana GreenConnect links your destinations, events and accommodation with live public transport timetables, from the doorstep to the destination. This is where its widget is hosted.

Served from a European CDN. Embed the latest release with one line, or pin a version and update when it suits you.

open the demo

Always the latest release.

This address always serves the current version. Fixes and new features reach your site without touching your embed code.

<script src="https://diana.zuugle-services.net/dist/DianaWidget.bundle.js"></script>

Or a fixed version.

Prefer to update on your own schedule? Load a pinned file such as DianaWidget.bundle-{{CURRENT}}.js. Pinned files never change; every version below stays available.

Configuration options and examples are in the documentation, changes in the changelog.
